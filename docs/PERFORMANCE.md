# SnapFire Mobile — AI 性能记录

> 状态：待真机执行（M8）。
> 目标：确认目标手机在“均衡”档下可连续运行，且不会明显发热降频。

## 测试方法

1. 通过 `npm run lan` 在手机上打开应用；
2. 进入房间并完成建档；
3. 在战斗中保持画面中有一名玩家，记录 60 秒；
4. 用浏览器性能面板或临时测试页记录：
   - 每次 Human 检测耗时（ms）
   - 实际检测频率（fps）
   - 页面帧率
   - 电量/温度变化（定性）
5. 分别测试“性能 / 均衡 / 精准”三档。

## 判定标准

- “均衡”档检测 ≥ 3 fps，页面无明显卡死（不超过 2 秒）；
- 连续 2 局不崩溃；
- 若低于 3 fps：默认降到“性能”，必要时只保留衣着识别或评估 MediaPipe。
