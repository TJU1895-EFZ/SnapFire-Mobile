# SnapFire Mobile — 联机验收记录

> 状态：待真机执行（M9）。
> 环境：桌面版房主 1 台 + 手机 1~2 台，同一局域网，室内正常照明。

## 0. 自动化回归（v1.2）

```bash
npm run typecheck
npm test
npm run build
npm run smoke:app
```

- 单元测试覆盖：武器定义 / 连发调度、阵营命名、长征导读内容与 10 秒门禁、
  换装几何、人脸-人体匹配。
- 浏览器冒烟覆盖：首页两级菜单、长征导读锁定与解锁、历史场景列表、
  长征大厅阵营命名、换装画布挂载、红军结算、换枪与步枪连发。
- 可选真人人像验证：准备一段 Y4M 假摄像头视频后运行
  `FAKE_VIDEO=<path> npm run smoke:app`，冒烟会采集建档并检查军服叠加。

## 2. 验收清单

### 2.1 加入与大厅

- [ ] 手机通过 HTTPS 代理打开首页（摄像头权限可获取）
- [ ] 输入地址 + 4 位房间号成功加入
- [ ] 错误房间号提示“房间号不正确”
- [ ] 错误地址/未开房提示连接失败
- [ ] 大厅实时显示昵称、队伍、准备、建档状态
- [ ] 队伍满员/房间满员提示正确
- [ ] 建房失败时仍停留在房间入口页，可修改后重试

### 2.2 建档与识别

- [ ] 建档页摄像头正常，显示分辨率
- [ ] 正面 + 背面采集成功；无人时提示“没有检测到人体”
- [ ] 保存后本机持久化，刷新后仍为“已建档”
- [ ] 桌面端能看到手机玩家“已建档”
- [ ] 手机能看到其他玩家建档后的特征同步（服务端 `gallery`）
- [ ] 准心对准敌人显示昵称/队伍；不确定时显示“目标未识别”
- [ ] 识别不确定的开火按未命中处理

### 2.3 战斗

- [ ] 进入战斗 3 秒内出现摄像头、枪械、准心
- [ ] 虚拟扳机可开火，有枪声/后坐力/枪口火焰
- [ ] 左侧面板可滑动选择目标，松开确认
- [ ] 命中敌人 -25 HP；4 枪击倒
- [ ] 命中队友不扣血并提示
- [ ] 目标阵亡/无敌/断线时不扣血
- [ ] 阵亡显示倒计时，5 秒后满血复活；2 秒无敌
- [ ] 比分、血量、倒计时在 1 秒内同步
- [ ] 手机切后台/断网后桌面看到离线状态
- [ ] 房主离开后手机收到断开提示并回首页

### 2.4 结算与持久化

- [ ] 时间到或击杀上限触发结算
- [ ] 结算页比分/个人数据与服务端一致
- [ ] 房主返回大厅，手机自动回到大厅
- [ ] 历史战绩保存到 IndexedDB；刷新后仍存在
- [ ] 连续进行 2 局不崩溃

### 2.5 PWA

- [ ] Chrome/Edge 出现安装提示
- [ ] 添加到主屏后独立窗口启动
- [ ] 离线打开首页正常
- [ ] 重新部署后（刷新在线时）能拿到新版本
